# Icebox

*Plain English: ideas we like but are deliberately not building yet. Nothing here gets built until the user moves it into the plan (the requirements file 02 and the task list 05).*

How it works:
- New ideas from conversations, research or feedback land here first, with where they came from.
- When an idea is picked up, it gets a user story in the requirements file (02), screens and wording in 03, tasks in 05, and its row here is marked "Moved to plan".
- Big planned releases (hi-fi prototypes, synthetic testing, client logins…) live in the PRD's roadmap (01, section 6), not here.
